# Forever-Yours-Mohin ✨

A romantic, interactive birthday celebration website crafted with love for Muskan from Mohin.

## ✨ Features
- 🔐 **Secret PIN Lock Gate**: Enter secret love PIN (or date) to unlock the experience.
- 🎵 **Romantic Music Player**: Plays *"Rathinamo (Female Version)"* by Saurav Srisan & Tanisha Gnanavel.
- 💌 **Letters Across the Miles**: 3 emotional long-distance message chapters with interactive heart counters.
- 📸 **Polaroid Memories Showcase**: Realistic fluttering polaroid memory cards featuring Mohin & Muskan.
- 🎂 **Interactive Cake Ceremony**: Virtual 3D-styled cake with interactive candles, realistic smoke puff, and confetti fireworks.
- 💖 **3D Flip Secret Note Cards**: Tap to reveal heartfelt love notes.
- 📜 **Wax-Sealed Love Letter**: Interactive unbroken wax seal that unveils a handwritten love letter.
- 📱 **Fully Responsive**: Optimized for all smartphones, tablets, and desktops.

## 🚀 How to Run Locally
Open `index.html` in any modern web browser or serve locally:
```bash
npx serve .
```
